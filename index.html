Diccionario Git Interactiva

Aprendiendo a trabajar con ramas

git init

Inicializa un nuevo repositorio local en la carpeta actual.

git clone

Descarga una copia exacta de un repositorio remoto.

git add

Prepara los cambios (staging) para ser incluidos en el próximo commit.

git commit -m "mensaje descriptivo"

Guarda la captura de los cambios preparados en el historial.

git status

Muestra el estado actual del directorio de trabajo y del área de preparación (staging).

git push

Sube los commits locales de la rama actual al repositorio remoto.
